Atlas

A map of which public companies depend on which others — built only from what those companies have already said in public.

The problem

When something happens in the world, the companies hit first are obvious.

The problem

The companies hit third are not. Nobody has a list of them.

Why this is hard

The obvious approach is to read big companies' filings. It does not work.

“We depend on a limited number of suppliers for certain components, including a single facility located in Asia.”
The shape of nearly every supplier disclosure in a large-cap filing

Supplier identities are commercially sensitive, so they are written out of the document on purpose. Build top-down and you get hedged legal language and an empty graph — four months in, after the pipeline already exists.

The idea

So we build it from the other end.

We measured it before building on it

Ten real filings, a keyword-and-gazetteer pass, no model involved.

Ichor Holdings' 10-K named Lam Research six times and Applied Materials six times. Ultra Clean's named the same pair.

Three rules, enforced in the schema — not in code review

What keeps it honest.

Every edge is cited

dependency_edge.chunk_id is NOT NULL. There is no way to write an edge without the sentence that proves it, even by accident.

·

The model never scores

It reads a sentence and reports what it says, with character offsets. Confidence and exposure come from versioned, tested code.

·

The graph knows when it knew

Every edge carries the date it became public. Every read goes through one as_of function. The backtest cannot see the future.

How it is built

Prose in, cited claims out.

Fetch

Filings, transcripts and decks from public sources, each with a licence row before an adapter exists.

→

Segment & chunk

Item boundaries, character offsets preserved end to end.

→

Filter

Lexicon + 59,567-name gazetteer. No model. Removes 85% of the text.

→

Extract

Schema-forced. Returns the span, never a score.

→

Resolve & score

Entity resolution, then deterministic weights.
